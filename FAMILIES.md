# Сім'ї (окремі списки)

У файлі **families.json** задаються сім'ї: кожна сім'я — це список Telegram **user_id** учасників. У кожної сім'ї свій список покупок.

## Формат

```json
{
  "family_1": [123456789, 987654321],
  "family_2": [111222333]
}
```

- Ключ — назва сім'ї (будь-яка, для себе).
- Значення — масив **числових** ID користувачів Telegram.

Якщо користувача немає в жодній сім'ї, він потрапляє в спільний список **default** (один на всіх таких користувачів).

## Як дізнатися свій ID

- Напиши боту [@userinfobot](https://t.me/userinfobot) — він покаже твій Id.
- Або відкрий профіль у веб-версії Telegram — ID буде в URL.

## Git і дані

- **families.json** — можна і потрібно комітити: там лише прив'язка ID до сімей. Коли пушиш в гіт нові ID, списки **не пропадають** — змінюється лише те, хто в якій сім'ї.
- **data.json** — додано в `.gitignore`. У ньому зберігаються самі списки покупок. Його **не пушити** в репо: тоді на сервері (наприклад Railway) залишається своя копія data.json, і у інших сімей нічого не зміниться і нічого не видалиться.

Підсумок: пушиш код + оновлений families.json — це безпечно. Списки кожного сервера живуть у своєму data.json окремо.
